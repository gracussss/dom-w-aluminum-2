Tu wgraj rysunki przekrojow od producenta (.svg / .png / .webp).

Podpiecie: pole `crossSections` rekordu systemu w src/catalog/dataset.ts

  crossSections: [
    {
      id: "poziomy",
      label: "Przekroj poziomy",
      imageSrc: "/przekroje/mb-86n-poziomy.svg",
      source: { label: "aluprof.com - rysunek techniczny", url: null, accessedAt: "RRRR-MM-DD" },
    },
  ]

Dopoki `imageSrc` jest puste, karta systemu pokazuje wlasny schemat
pogladowy dobrany do typu konstrukcji - i mowi o tym wprost.

UWAGA: publiczna dostepnosc pliku u producenta NIE jest zgoda na jego
publikacje na stronie komercyjnej. Wymagana pisemna zgoda - patrz MATERIALY.md.
